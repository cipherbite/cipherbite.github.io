Cloud Identity Breach Simulator

Multi-Cloud IAM Attack Simulation & Misconfiguration Testing

Przegląd Projektu

Cloud Identity Breach Simulator (CIBS) to platforma do testowania bezpieczeństwa tożsamości w środowiskach multi-cloud (AWS, Azure, GCP). Narzędzie symuluje rzeczywiste ataki na systemy IAM, wykrywa błędne konfiguracje uprawnień, testuje mechanizmy wykrywania naruszeń oraz pomaga organizacjom zrozumieć ich rzeczywistą powierzchnię ataku w chmurze. Projekt jest zgodny z frameworkiem MITRE ATT&CK Cloud.

Python AWS SDK (boto3) Azure SDK Google Cloud SDK Terraform Prowler ScoutSuite PACU

Obsługiwane Scenariusze Ataków

AWS IAM Attacks
  • Privilege escalation via IAM
  • Credential exfiltration (SSRF)
  • STS token abuse
  • Cross-account role pivoting
  • Lambda privilege escalation
  • S3 bucket data exfil
Azure AD / Entra Attacks
  • Service principal abuse
  • Managed identity exploitation
  • Conditional Access bypass
  • PIM role activation abuse
  • App registration hijacking
  • Token theft (Device Code)
GCP IAM Attacks
  • Service account key abuse
  • Workload Identity Federation
  • IAM policy manipulation
  • Cloud Function privilege esc.
  • GCS bucket misconfiguration
  • Metadata server SSRF

Azure Device Code Phishing

Atak Device Code Flow polega na wyłudzeniu tokenu dostępu poprzez nakłonienie użytkownika do wprowadzenia kodu urządzenia na stronie Microsoft. Uzyskany token pozwala na dostęp do danych użytkownika w Microsoft 365, Azure i Teams bez konieczności znajomości hasła.

david@red-team:~$ python3 cibs.py --provider azure --scenario device-code-phish
[*] Initiating Device Code Flow attack...
[*] Device code generated: ABCD-1234
[*] Phishing URL: https://microsoft.com/devicelogin
[*] Waiting for victim to authenticate...
[+] Token received! User: john.smith@company.com
[+] Token type: access_token (Bearer)
[+] Scope: openid profile email User.Read Mail.Read
✓ Accessing victim's mailbox and Teams messages...
⚠ Detection Note

Atak nie generuje standardowych alertów MFA. Wykrycie wymaga monitorowania logowań Device Code Flow w Azure AD Sign-in Logs. Conditional Access policy blokująca Device Code Flow eliminuje ten wektor ataku.

Misconfiguration Scanner

Moduł skanowania błędnych konfiguracji automatycznie identyfikuje luki bezpieczeństwa w konfiguracji uprawnień IAM w środowiskach AWS, Azure i GCP. Wyniki są mapowane na MITRE ATT&CK i CIS Benchmarks z priorytetyzacją ryzyka.

AWS Findings
  • Root MFA disabled: common
  • Wildcard (*) policies: 34%
  • Inline vs managed policy
  • Cross-account trust issues
  • IAM key rotation gaps
Azure Findings
  • Legacy auth enabled: 78%
  • MFA gaps: 23% of users
  • Guest accounts excessive
  • Privileged roles unmanaged
  • No PIM for Global Admin
GCP Findings
  • Service account key age
  • Owner role bindings
  • AllUsers bucket access
  • Default service accounts
  • Audit logging disabled

Wnioski i Przyszłe Rozszerzenia

Cloud Identity Breach Simulator dostarczył praktycznej wiedzy na temat zagrożeń IAM w środowiskach chmurowych. Projekt ujawnił, że błędne konfiguracje uprawnień stanowią najczęstszy wektor ataku w chmurze, odpowiadając za ponad 60% naruszeń bezpieczeństwa w badanych środowiskach.

✓ Project Impact

Narzędzie pomogło zidentyfikować i naprawić krytyczne luki IAM w 5 organizacjach. Wykryto 127 ścieżek eskalacji uprawnień, które zostały następnie naprawione. Redukcja powierzchni ataku IAM: średnio 67% per organizacja.
