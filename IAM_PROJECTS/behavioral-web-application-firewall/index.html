Behavioral Web Application Firewall

ML-Based Anomaly Detection — Beyond Static Rules

Overview

Python WAF that builds a behavioral baseline per user session and detects attacks by identifying deviations from that baseline — rather than matching against a fixed signature list. Catches novel SQLi, XSS, and path traversal variants that evade rule-based WAFs. Deployed as a Flask middleware proxy in front of any web application.

Python Flask scikit-learn Redis Isolation Forest OWASP

How It Works

1. Baseline Learning

Collects normal request patterns per user — request rate, parameter lengths, endpoint sequences, user agent consistency — over a configurable training window.

2. Feature Extraction

Each request is converted to a 24-dimensional feature vector covering URL entropy, payload structure, HTTP method frequency, and session consistency.

3. Anomaly Scoring

Isolation Forest assigns an anomaly score per request. Scores above the threshold trigger blocking and alerting in real time.

Deployment

Runs as a reverse proxy. Drop-in deployment — no application changes required.

$ git clone https://github.com/cipherbite/behavioral-waf.git && cd behavioral-waf
$ pip install -r requirements.txt
$ python3 waf.py --target http://app:8080 --mode training --duration 3600
[*] Training mode — collecting baseline for 3600 seconds
[*] Proxying traffic to http://app:8080
[+] Baseline model saved: models/baseline_20240115.pkl
$ python3 waf.py --target http://app:8080 --mode enforce --model models/baseline_20240115.pkl
[*] Enforce mode active — anomaly threshold: 0.85

Attack Detection in Action

SQL injection attempt flagged by anomaly score — no signature match needed.

GET /search?q=shoes score=0.12 — ALLOW
GET /search?q=boots score=0.09 — ALLOW
GET /search?q=' OR 1=1-- score=0.97 — BLOCK (SQLi pattern)
GET /search?q=';DROP TABLE users-- score=0.99 — BLOCK (SQLi pattern)
POST /admin/../../../../etc/passwd score=0.96 — BLOCK (path traversal)
