Behavioral Web Application Firewall

ML-Powered Anomaly Detection for Web Traffic

Przegląd Projektu

Behavioral Web Application Firewall (BWAF) to zaawansowany system ochrony aplikacji webowych wykorzystujący uczenie maszynowe do analizy zachowania użytkowników w czasie rzeczywistym. W odróżnieniu od tradycyjnych WAF opartych na sygnaturach, BWAF buduje dynamiczne profile behawioralne dla każdego użytkownika i sesji, wykrywając anomalie wskazujące na ataki takie jak SQL Injection, XSS, CSRF, credential stuffing czy automatyczne boty.

Python 3.10+ Flask Scikit-learn TensorFlow Redis PostgreSQL Docker Nginx

Behavioral Profiling Engine

Silnik profilowania behawioralnego buduje wielowymiarowy profil każdego użytkownika na podstawie cech takich jak: timing między żądaniami, sekwencje URL, wzorce parametrów, Agent-String, geolokalizacja IP oraz charakterystyka nagłówków HTTP. Odchylenia od ustalonego profilu powodują podwyższenie score ryzyka sesji.

Feature Extraction
  • Request timing analysis
  • URL sequence patterns
  • Parameter entropy scoring
  • HTTP header fingerprint
  • Mouse/keyboard dynamics
  • Session duration modeling
ML Models
  • Isolation Forest (anomaly)
  • LSTM sequence analysis
  • Random Forest classifier
  • One-class SVM
  • Autoencoder (reconstruction)
  • Ensemble voting
Response Actions
  • Block / rate-limit
  • CAPTCHA challenge
  • Honeypot redirect
  • Tarpit (slowloris)
  • Alert + log forensics
  • IP reputation update

Credential Stuffing Protection

Credential stuffing stanowi jedno z największych zagrożeń dla aplikacji webowych. BWAF wykrywa ataki poprzez analizę wzorców: szybkość logowań, różnorodność par user/password, wzorce timing, geolokalizację i korelację z bazą danych wyciekłych credentiali.

Wnioski i Przyszłe Rozszerzenia

Behavioral WAF wykazał znaczącą przewagę nad tradycyjnymi WAF opartymi na sygnaturach, szczególnie w wykrywaniu zaawansowanych, dostosowanych ataków oraz zachowań botów nowej generacji. Podejście behawioralne pozwala na wykrywanie ataków zero-day bez konieczności aktualizacji sygnatur.
