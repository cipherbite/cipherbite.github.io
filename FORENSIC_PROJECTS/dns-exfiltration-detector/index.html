DNS Exfiltration Detector

Real-time Detection of Data Theft via DNS Tunneling

Overview

Python tool that detects data exfiltration through DNS queries in real time. Captures live traffic with Scapy and analyzes each DNS query for high entropy, Base64/hex-encoded subdomains, and abnormal query frequency — the hallmarks of DNS tunneling.

Python Scapy Pandas Wireshark

How It Works

Monitors a network interface and scores each DNS query against three detection methods.

$ sudo python3 dns_detector.py -i eth0 --entropy-threshold 4.0
[+] DNS Exfiltration Detector started
[*] Monitoring: eth0 — entropy threshold: 4.0
[ screenshot: terminal — dns_detector.py running with live DNS query stream ]

Detection Methods

Entropy Analysis

Calculates Shannon entropy per subdomain label. Values above 4.0 indicate random or encoded data.

Pattern Matching

Regex detection of Base64, hex-encoded strings, and known DNS exfiltration tool signatures.

Frequency Analysis

Tracks query rate per source IP and domain. Sudden spikes indicate active tunneling.

Core Detection Logic

Entropy calculation is the primary signal — encoded payloads have high Shannon entropy.
