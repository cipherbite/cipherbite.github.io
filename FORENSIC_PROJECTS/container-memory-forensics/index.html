Container Memory Forensics

Live Memory Analysis for Docker & Kubernetes — Without Stopping Services

Overview

Tool for forensic analysis of running Docker and Kubernetes containers in production environments. Acquires memory without stopping the container, then runs Volatility3-based analysis to detect cryptominers, rootkits, container escapes, and lateral movement. Uses eBPF for syscall monitoring and a custom kernel module for safe memory acquisition.

Docker Kubernetes Volatility3 Python C++ eBPF Linux Kernel

Deployment

Runs as a DaemonSet — one agent per node, auto-detects the container runtime.

$ git clone https://github.com/cipherbite/container-memory-forensics.git
$ kubectl apply -f deploy/kubernetes/
daemonset.apps/forensics-agent created
service/forensics-api created
configmap/forensics-config created
[ screenshot: kubectl get pods -n forensics — daemonset pods running on cluster nodes ]

Memory Acquisition

Acquisition uses /proc/[pid]/mem combined with a kernel module for protected regions. SHA-256 hash generated for chain-of-custody.
