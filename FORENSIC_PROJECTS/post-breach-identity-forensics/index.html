Post-Breach Identity Forensics

PowerShell & Python Framework — Active Directory Compromise Analysis

Overview

Framework for post-incident identity analysis in Active Directory and Azure AD environments. Automates detection of compromised accounts, lateral movement paths, privilege escalation, and Kerberos-based attacks — reducing breach investigation time from days to under 30 minutes.

Detection Capabilities

Dormant Account Detection

Identifies inactive privileged accounts — common targets for attackers who need persistence without detection.

Lateral Movement Tracking

Maps authentication patterns across systems to surface credential-hopping and pass-the-hash paths.

Privilege Escalation

Detects unusual group membership changes, AdminSDHolder modifications, and ACL abuse.

Golden Ticket Detection

Identifies Kerberos TGT anomalies — unusual encryption types, lifetime values, and cross-domain usage.

DCSync Attack Detection

Monitors replication events for unauthorized DC sync operations indicating credential dumping.

Shadow Admin Discovery

Finds accounts with privileged ACL permissions that aren't members of standard admin groups.
